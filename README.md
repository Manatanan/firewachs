# 🔥 Fire Watch

ระบบเฝ้าระวังและแจ้งเตือนจุดความร้อนจากข้อมูลดาวเทียม GISTDA VIIRS

## 📌 เกี่ยวกับโครงการ

Fire Watch เป็นระบบสำหรับติดตามจุดความร้อนและช่วยแจ้งเตือนเหตุการณ์ไฟในพื้นที่ โดยนำข้อมูลจุดความร้อนจาก GISTDA VIIRS มาประมวลผลบน Backend และแสดงผลผ่านเว็บไซต์

ระบบสามารถส่งการแจ้งเตือนไปยังกลุ่ม LINE ที่เกี่ยวข้อง และเชื่อมต่อกับ ESP32 สำหรับการแจ้งเตือนในพื้นที่

## 🚀 ความสามารถหลัก

* 🛰️ ดึงข้อมูลจุดความร้อนจาก GISTDA VIIRS
* 🗺️ แสดงตำแหน่งจุดความร้อนบนแผนที่
* 📍 แสดงจังหวัด อำเภอ และตำบลของจุดเกิดเหตุเมื่อมีข้อมูล
* 👮 ส่งข้อมูลพิกัดและ Google Maps ให้กลุ่มเจ้าหน้าที่
* 👥 ส่งข้อมูลพื้นที่ให้กลุ่มประชาชนเพื่อช่วยติดตามสถานการณ์
* 🔥 รองรับโหมด DEMO สำหรับทดสอบระบบ
* 📡 รองรับ ESP32 หลายบอร์ด
* 🎯 เลือก ESP32 ที่รับผิดชอบตามตำแหน่งและระยะที่กำหนด
* 🔐 มีระบบ Login สำหรับผู้ใช้งาน
* ⚡ Backend ใช้ Node.js และ Express

## 🏗️ โครงสร้างระบบ

```text
GISTDA VIIRS
     ↓
Fire Watch Backend
     ↓
ตรวจสอบตำแหน่งและพื้นที่รับผิดชอบ
     ↓
 ┌───────────────┬────────────────┐
 ↓               ↓                ↓
เว็บไซต์       LINE เจ้าหน้าที่   LINE ประชาชน
 ↓               ↓
แผนที่          พิกัด + Google Maps
                 ↓
              ESP32
```
