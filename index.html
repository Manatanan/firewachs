📡 GISTDA API

ระบบรองรับ GeoJSON แบบ features → geometry.coordinates → properties

⚠️ อย่าใส่ API Key จริงลงในไฟล์ที่เผยแพร่สาธารณะบน GitHub เพราะคนอื่นสามารถเปิดดู Source Code ได้ สำหรับใช้งานจริงควรทำ Backend/Proxy เก็บ Key ไว้ฝั่งเซิร์ฟเวอร์

🧪 โหมดสาธิตสำหรับกรรมการ

ปุ่มนี้ใช้จำลองสถานการณ์โดยไม่ต้องรอข้อมูลดาวเทียม เหมาะสำหรับสาธิตการทำงานของระบบ ESP32

🔌 เชื่อมต่อ ESP32

ESP32 ต้องอยู่ในเครือข่ายเดียวกับคอมพิวเตอร์/โทรศัพท์ และต้องเปิด Web Server พร้อม Endpoint /api/alert

🗺️ แผนที่จุดความร้อน

ตำแหน่ง ESP32 จุดความร้อน จุดนอกพื้นที่แจ้งเตือน
